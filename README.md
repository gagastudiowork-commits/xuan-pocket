# 小步影像

小步工具所的照片整理工具。可在瀏覽器中選取多張照片、調整最大邊長及壓縮品質，並逐張下載。直接開啟 `index.html` 即可使用。

## 版本紀錄

### v0.4

- 「輸出格式」同時指定轉檔及檢查目標（JPG、WebP 或 PNG）。開始處理時會記住本批設定。
- 可選填每張照片的大小上限，支援正整數與小數。例如 500 KB 或 0.5 MB。1 KB = 1,024 bytes，1 MB = 1,048,576 bytes。留白時只檢查格式。
- 每張照片依實際輸出 MIME 類型及位元組數判定。大小剛好等於上限即符合；超出或格式不符會列出原因，仍可下載。瀏覽器若將 WebP 改為 PNG，結果會顯示 PNG 並使用 .png 副檔名。
- 上限僅供檢查。若要縮小檔案，可自行調整最大邊長或壓縮品質後重新處理。

### v0.3

- 處理中可清除或重新選圖，畫面只顯示目前批次的進度與下載連結。
- 新批次會等待上一張圖片結束處理，並逐張釋放畫布。單張失敗時會顯示檔名，繼續處理其餘照片。

### v0.2

- 網站改名為「小步影像」，品牌顯示為「小步工具所」，下載檔名使用 `_little-step`。
- 主要文字以 16px 為基準，主要操作文字 16–18px，按鈕與下載連結高度至少 48px。
- 窄螢幕改為單欄輸出設定與全寬操作按鈕，調整文字對比、鍵盤焦點與長檔名換行。
- 沿用裝置端多圖處理、比例縮放、JPG／WebP／PNG 輸出與逐張下載。

### v0.1

- 原名 XUAN Pocket，提供照片選取、壓縮、尺寸調整與下載。
